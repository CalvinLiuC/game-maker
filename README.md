# game-maker

一个卡牌构筑 roguelike 原型。核心机制是「翻倍引擎」：打出一张牌后，选择**加仓**（50% 翻倍，失败归零）或**平仓**（锁定结算）。每次加仓都要付手续费。没有怪物，节点是「合约」（在 3 手内凑够指定点数），Boss 是和庄家对赌。

设计文档：[docs/superpowers/specs/2026-10-13-gamble-roguelike-design.md](docs/superpowers/specs/2026-10-13-gamble-roguelike-design.md)

## 原型

`prototype/index.html` 是零依赖的单文件浏览器原型，双击即可玩。这是「阶段 0」版本，规则只有四条：

1. 牌一张一张发，每张一个数字。加仓：按概率翻倍，失败归零。平仓：收下。
2. 每次加仓扣 1 本金。
3. 一份合约 = 把 9 张牌打完一遍，凑够要求的点数。差多少扣多少本金；多出来的每 3 点回 1 本金。
4. 每份合约结束二选一，替换掉一张普通牌。8 份合约打完算赢，本金归零算输。

结束画面显示贪心率、爆仓次数、最大连翻、手续费总支出，用来判断「翻倍按钮」本身是否上头。后续功能按设计稿第 9 节的顺序逐个加回。

## 状态

原型验证阶段。先玩原型确认「翻倍按钮」本身上头，再定正式技术栈。
